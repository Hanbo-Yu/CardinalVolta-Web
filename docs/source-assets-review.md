# source_assets 素材审阅与下一版使用方案

> 本文件记录首次素材审阅。当前版式以 `design-system.md` 为准：金属照片用于首屏，工业设施用于大图叙事；电表和彩色热流已退出当前页面。自有设备照片和视频属于后续升级素材，不是完成本版的前提。

## 结论

已逐项检查 80 个文件，共约 83.41 MiB：75 张位图、5 个 SVG。没有视频、GIF 动画或 3D 模型。

这批素材能支持下一版的正式品牌标识、高清行业展示、团队信息及更完整的技术叙事。动态首屏仍需专门制作；现有图片可以成为视觉参考和静态后备图。

## 视觉方向

1. **首屏：热的运动。** 使用正式 Logo、大字号标题与定制的动态热流。素材中的彩色热流可作参考，不直接保留整套粉绿配色。热流由散到聚，再转为有方向的能量运动。
2. **品牌章节：材料与能量。** 以 `Copper1.jpg` 的金属曲面作为大画幅过渡，让画面随滚动缓慢移动；在留白区域放一条清晰的价值陈述。
3. **技术章节：固定画面，逐步揭示。** 用两张技术图作为内容依据，重新制作简洁的可缩放矢量示意。桌面随滚动展开，手机顺序呈现并保留手动切换。
4. **行业章节：大图与切换。** 以钢铁和化工高清照片为主要画面，行业文字切换时同步更换图像与说明。
5. **人物与机构：可信度。** 替换人物和机构的低清素材，以一致的尺寸、留白和克制的入场动画呈现。

动画遵循 `prefers-reduced-motion`，不劫持正常滚动；手机提供轻量显示。静态图片的缩放/视差可以增加空间感，但不能冒充真实视频或可旋转的 3D 产品。

## 暂不优先用于主视觉

- `White hall way.jpg`、`White hallway 2.jpeg`：科幻走廊与公司业务联系较弱。
- 烟花、火箭、地球夜景：画面有冲击力，但不如工业热回收主题直接。
- 风车/太阳能板：容易把主营业务理解为风电或光伏。
- 蓝色数字城市、电网科技背景：视觉语言与品牌红及工业材料方向不一致。
- `More coming*.png`、`image.png`：占位图或把文字烘焙进图片的素材，不作为正式内容。
- 约 274×158 的 AVIF：仅作缩略图参考，不用于大幅背景。

## 文件处理注意点

- 保留 `source_assets` 原始文件。选中的文件另导出到 `public/assets`，不把整个 83 MB 素材库放进部署目录。
- 高清照片按实际显示尺寸生成 WebP / AVIF 与必要的响应式尺寸，避免把 5–10 MB 原图直接加载到首页。
- `WechatIMG17351.jpg` 实际为透明 PNG；若临时使用原图，应正确命名并配合浅色底显示。最终建议用重新绘制的 SVG 示意图替代。
- 发现两组字节完全相同的重复文件：两张 `AdobeStock_281853233_edited...jpg`；两张 `Power meter...jpg`。每组只取一份。
- 行业图片已使用对应原图替换，并修正图片替代文本。
