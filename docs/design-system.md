基准：`design-concepts/cardinal-layout/index.html`。本次将用户确认的静态排版落实到 React 官网。

冷白 → 深酒红 → 冷灰 → 冷白 → 深酒红。用色块与留白建立章节，不添加未确认的主视觉。

## 排版与适配

- 正文、导航、标题均为 Geist Variable，Logo 使用既有 SVG。
- 最大容器 1600 px，桌面边距 56 px，中等屏幕 36 px，手机 24 px。
- 首屏大字、左下说明、右下文字链接；手机按阅读顺序纵排。
- 技术区三列文字，手机转为三行；没有未经确认的设备图。
- 行业区文字与单张照片左右排；团队以两张中小尺寸彩色头像承载真实信息。
- 导航在手机直接展示；原生锚点、跳过导航链接、键盘焦点样式。不依赖滚动脚本显示内容。
- 当前范围为静态设计落地，未加入滚动动画。

## 素材

官方 Logo；Petrochemical.jpg 的响应式 WebP；Nan Ge 与 Aimy Bazylak 头像。保留原色与清晰来源说明。金属建筑、电表、粒子图、旧版示意组件未加载。

## 内容边界

首页中的 News 显示英文空状态，真实新闻以后填写在 `src/content.js`。移除设计稿的中文审稿提示与说明链接；未制造公告、孵化器、客户或产品信息。

生产预渲染脚本保持原有隔离配置，避免 Cloudflare 插件干扰；只发布 dist。
