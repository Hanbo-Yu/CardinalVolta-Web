这是首页的静态排版提案：用字体、留白与色块建立主次，用真实图片解释行业与团队。五个导航栏目在本稿中对应首页章节，独立内页尚未展开。

01 / 配色判断

冷白#F5F6F4
石墨黑#25292A
品牌红#D72323
深酒红#411F27
浅暖白 / 杏粉#EDC9BD

我的判断：你们的红色 Logo 已经提供了品牌起点。冷白让文字与工程照片清楚；石墨黑承担阅读；品牌红只突出关键标题。技术与联系章节用深酒红延伸同一个红色系，浅暖白用于其上的大标题。浅暖白只出现在深色章节，不把全站铺成米色。

首页阅读顺序：冷白 → 深酒红 → 冷灰 → 冷白 → 深酒红。这版先检查每一屏的颜色比例，不用渐变装饰遮盖排版问题。后续动效再处理滚动时的色彩衔接。

02 / 字体与页面比例

正文、导航、标题统一使用 Geist。Logo 保留现有官方 SVG；它的字形属于标志本身。桌面正文约 20–22 px，说明 15–16 px，大标题约 64–136 px，依视口调整；手机正文 18–19 px。少量小字仅用于章节名称、人物职务和图片说明。

首屏：一句价值主张 + 一段解释 + 技术入口
Technology：概念文字 + 三步过程，不伪造设备外观
Applications：行业语境图 + 应用范围
About：真实头像 + 创始人信息
News：真实新闻的文字列表位置
Contact：明确的邮箱入口

04 / 还缺什么，按用途补

现在最值得补：新闻与孵化器信息。

你已有的新闻：标题、日期、正文或链接；图片可选。新孵化器：正式名称、入选时间、准确关系描述、可使用的官方 Logo / 公告链接。收到真实信息后，可在首屏下放一行简短公告，并在 News 展开。

Technology 内页需要内容确认，不必先买图片。

请核对现有 ORC 图哪些部分是可以公开的，提供你们与常规 ORC 的差异、适用条件和可公开参数。当前三步文字只是工作原理概览，没有加入效率、回本周期或部署成果。

真实设备 / 实验照片属于后续补强。

如果以后要展示产品外观、实验过程或部署案例，需要对应的真实照片或获准公开的 CAD。现在没有就不安排“产品大图”或“客户案例”章节。本稿不依赖这批素材才能成立。

无需为了这版补拍团队合影、购买工业视频或制作 3D 渲染。头像先用现有两张；News 用文字列表；首屏保持纯排版。

05 / 本稿范围

独立 HTML/CSS 静态设计稿，放在 design-concepts/cardinal-layout。没有修改 React 官网，没有部署。没有新生成图片；没有编造新闻、客户、项目或孵化器。英文品牌文案为提案，新闻框中的中文为审稿占位，正式上线时应替换或移除。

选定排版之后，再制作章节色彩衔接与进入动画；本轮不加入滚动特效。首页可双击 index.html 打开，所有显示素材与字体均在本文件夹中。
