# News 页面设计稿

双击 index.html 查看完整排版。方括号中的文字为明确的字段占位；未使用虚构新闻、日期或代替图片。三条占位只展示排版，不代表实际新闻数量。

## 页面关系

- 官网导航 News → /news/。
- 首页 Latest news 最多显示 3 条，View all news → /news/。
- News 页最新一条使用深酒红重点区，其余按日期列表排列。
- 有真实原文链接时，标题与阅读入口直接打开原文；内部新闻正文页尚未制作。
- 尚无数据时，实际网站显示英文空状态，设计占位不进入正式页面。

## 所需内容

标题、日期、链接、简短摘要（可选）。新闻配图非必需，有真实相关照片再按内容需要安排。

## 技术

实现读取同一份 src/content.js。构建已生成 dist/news/index.html，无需数据库与路由服务。设计稿独立保存。
