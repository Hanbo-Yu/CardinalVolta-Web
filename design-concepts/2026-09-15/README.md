# Cardinal Volta — 三版视觉概念

本轮仅制作设计图，没有修改网站代码。使用内置 imagegen 生成；完整提示词见 prompts.json。

| 方向 | 核心隐喻 | 色彩过渡 | 拟议滚动行为 |
| --- | --- | --- | --- |
| A / Thermal field | 分散的热被收集成有方向的能量 | 浅底 → 朱红热场 → 浅底 | 热场缓慢聚拢，占满视野，再收束成技术章节中的路径 |
| B / Heat into current | 从热的强度进入可控的电力 | 深酒红 → 炽红 → 杏色光 → 近白 | 首屏热流横向推进，滚动时光域扩大，转为明亮的技术章节 |
| C / See the invisible | 把看不见的工业余热显影 | 冰灰 → 靛蓝与热红 → 冰灰 | 扫描带揭示热源，镜头沿热路径进入原理示意 |

每版上下部分用于表现首屏、滚动过渡和技术章节的视觉关系；静态图不能验证动画节奏。图中的字标、技术符号和文案是概念占位，最终版应使用正式 Logo、可访问的网页字体和经核实的工程说明。C 的工业热成像为概念图，不是实测数据。现阶段重点比较视觉方向，下一轮再制作选定方向的动态样稿。

排版原则：同一字体家族贯穿标题和正文；小字仅保留导航、操作与必要的内容说明。不同字体并非天然错误，但上一版的等宽编号没有足够的信息作用。
