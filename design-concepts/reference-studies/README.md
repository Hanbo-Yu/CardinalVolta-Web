# Reference-led webpage studies

Open index.html for the four-way review. Each HTML file is a standalone design proposal, separate from the React website. Hero JPEGs were captured from the rendered HTML through the browser. Full-page JPEGs combine overlapping browser viewport captures at recorded scroll positions; capture-record.json records the scale and coordinates. No UI content was painted or synthesized.

References: https://curaclimate.com/ ; https://capturacorp.com/ ; https://sublime-systems.com/ ; https://www.brimstone.com/

This is a close structural design study authorized by the user. No competitor logos, marketing claims, imagery or commercial font files were copied. Supplied industrial photos are contextual imagery; the SVG is a simplified ORC diagram. Website source and deployment settings are unchanged.

Motion shown in HTML: short reveal, restrained image parallax, circuit flow and light scroll movement. These are rough motion cues, not a recreation or validation of the references' entire animation systems. Reduced-motion preferences are respected. Screenshots remain static.
